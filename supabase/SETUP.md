# Archived Supabase proposal

The migrations in this folder belong to the preserved v1 prototype (Git commit e8ef61d). They have not been applied by this rebuild and are not a working integration for the version-2 save format. Do not deploy them as the current backend.

The published v2 chapter saves checkpoints and personal ghosts locally. A dedicated Last Tether Supabase project was not present in the connected account; unrelated databases were left unchanged, and no paid project was created.

Future cloud work requires a dedicated project, version-2 checkpoint validation, account linking for cross-device access, owner-only row policies, and live authorization tests. Public competitive scores additionally require server-side validation; client-reported completion is not cheat resistant.
